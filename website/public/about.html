What BountyRadar is — and is not

BountyRadar is an intelligence and alerting layer, not a bounty marketplace. We do not hold funds, perform KYC, or settle payouts. We turn a noisy firehose of bounties into a ranked, agent-consumable feed.

We do

  • Aggregate across 7 source classes
  • Score for agent-solvability, freshness, competition, reward
  • Alert subscribers and agents (email / Slack / MCP)
  • Flag honeypots and ToS-risky programs

We don't

  • Settle payouts or hold funds
  • Run KYC / compliance
  • Compete with agent farms
  • Encourage agents to spam HackerOne

MCP server

The same feed is available programmatically. An agent connects via initialize → get_bounty_feed({max_competition:3, agent_solvable_min:0.7}) → picks the top item. Monetized per event on Apify — no monthly fee.

The moat

Anyone can scrape a bounty board. The scarce layer is judgment: scoring each bounty for whether an agent can actually solve it, how fresh it is, and how saturated the competition already is. That is what converts noise into a feed agents trust.

Partnerships

ClawHunt (爪寻) is a direct competitor-as-marketplace in China. We treat it as a partner candidate: BountyRadar is the upstream intelligence feed; ClawHunt is the settlement layer. We index, they settle.
